# WebLarek Express — Backend

Серверная часть интернет-магазина WebLarek, разработанная на Node.js, Express и TypeScript.

## Технологии

- Node.js и Express
- TypeScript
- MongoDB и Mongoose
- Joi и Celebrate — валидация входящих запросов
- Winston и Express-Winston — логирование запросов и ошибок
- dotenv — работа с переменными окружения

## Установка и запуск

1. Перейдите в директорию `backend`.
2. Установите зависимости:

   `npm install`

3. Создайте файл `.env` на основе `.env.example` и настройте подключение к MongoDB.
4. Убедитесь, что MongoDB запущена.
5. Запустите сервер:

   `npm run dev`

Для обычного запуска:

`npm run start`

## Доступные команды

- `npm run dev` — запуск сервера в режиме разработки
- `npm run start` — запуск сервера
- `npm run build` — компиляция TypeScript
- `npm run lint` — проверка кода ESLint

## API

### GET /product

Получение списка товаров.

Ответ содержит массив `items` и количество товаров `total`.

### POST /product

Создание нового товара.

Поля: `title`, `image`, `category`, `description`, `price`.

### POST /order

Оформление заказа.

Поля: `payment`, `email`, `phone`, `address`, `total`, `items`.

Сервер проверяет наличие товаров, возможность их продажи и соответствие итоговой суммы ценам в базе данных.

При успешном оформлении возвращает идентификатор заказа и итоговую стоимость.

## Обработка ошибок

Для некорректных запросов используются HTTP-статусы `400`, `404` и `409`. Непредвиденные ошибки обрабатываются централизованно со статусом `500`.

Запросы записываются в `request.log`, ошибки — в `error.log`. Файлы логов исключены из Git.

## Статические файлы

Изображения товаров находятся в директории `public/images` и доступны по адресам `/images/имя-файла`.

## Переменные окружения

Пример настроек находится в файле `.env.example`. Файл `.env` не должен добавляться в Git.
